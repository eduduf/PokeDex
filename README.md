# Pokédex

## Apresentação

A Pokédex é uma aplicação web para explorar Pokémon. É possível pesquisar por nome ou número, filtrar os resultados por tipo e ordenar a lista por nome ou número. Os cards exibem informações e artes oficiais dos Pokémon.

## Ferramentas Utilizadas

- **HTML, CSS e JavaScript:** estrutura, estilos e interatividade do frontend.
- **Node.js e Express:** criação da API backend.
- **CORS:** permite requisições à API entre diferentes origens.
- **PokéAPI:** fonte de dados e imagens oficiais dos Pokémon.
- **Google Fonts e CDNFonts:** fontes utilizadas na interface.
- **Git e GitHub:** controle de versão e hospedagem do código.
- **Render:** plataforma para publicação do projeto.
